Recognition of the Registered Reports

Published on Jan 30, 2025
DOI GitHub OSF
Description
This study conducted a matched meta-evaluation of 119 pairs of original research articles (Registered Reports [RRs] vs. traditional non-registered reports [non-RRs]) across 33 psychology journals, matching them by journal, time, and research topic. The findings indicate that while RRs are designed to improve scientific transparency and reduce bias, they have not yet garnered higher academic or public attention compared to traditional reports; in fact, RRs were found to receive relatively fewer citations.
My Responsibilities
When I first joined this project, it was nothing more than a rough concept with no existing roadmap to follow. I brainstormed several analytical approaches and created the visualizations that clearly highlight how RRs and non-RRs differ across various dimensions. I wrote over 95% of the code and drafted the entire Methods and Results sections. Regarding the Introduction and Discussion sections, I proposed several potential narrative directions and thematic outlines grounded in the results we obtained. I also took the lead in addressing the statistical concerns raised by the reviewers during the peer-review process.

Reliability of the Self‑Matching Task

Published on Jan 2, 2025
DOI GitHub OSF
Description
A cognitive paradigm may exhibit highly robust effects at the group level while showing poor reliability at the individual level, a phenomenon known as the reliability paradox. Based on 42 publicly available datasets, we found that this reliability paradox is also present in the Self-Matching Task (SMT).
My Responsibilities
I took on most of the responsibilities throughout the project. I managed the full data curation process, including searching for open datasets and contacting authors to obtain raw data. I also wrote the preregistration and drafted the manuscript. To improve the reproducibility and overall manageability of the project, I developed two R packages for data splitting and for computing split-half reliability across six different metrics.

Tutorial of R package binaryRL

Drafted on Apr 28, 2026
DOI GitHub OSF
Description
Reinforcement learning often presents a steep learning curve for psychologists, especially when it comes to building MDPs and estimating free parameters with optimization algorithms. The binaryRL package simplifies this process with a modular, Lego-like design that breaks the framework into easy-to-understand components. Using straightforward if-else logic to define cognitive processes, researchers can run the entire workflow—from model construction and parameter recovery to model fitting and visualization—with much less coding overhead.

Remake of RLWMH with multiRL

Updated on Apr 26, 2026
GitHub
Description
A recent reanalysis by Anne G. E. Collins (2025) suggests that learning in the RLWM paradigm may be driven more by Habit (H) and Working Memory (WM) than by a slow reinforcement learning (RL) process. In this project, I used the custom multiRL R package to re-implement these models, starting from simple models (RL, WM, H) and gradually building more complex combinations to evaluate parameter recovery and parameter redundancy. The results showed that a simple 3-parameter HWM model was enough to recover the main experimental effects, while adding more parameters often reduced model performance, consistent with Occam’s razor. In addition, although different estimation methods performed reasonably well for simple models, only simulation-based inference (SBI) methods maintained good parameter recovery as model complexity increased, with ABC showing the strongest overall performance.

Meta-analysis of Decision-Making Game

Started on Dec 5, 2023
DOI GitHub
Description
This three-level meta-analysis of 41 studies (N = 8376) reveals that business decision-making games significantly enhance training effectiveness with a moderate overall effect (g = 0.53). The games effectively improve reactions (g = 0.44), learning processes (g = 0.66), and performance (g = 0.45), with the strongest impact on trainee motivation (g = 0.85). These positive outcomes remain robust across various participant types, game designs, and academic fields, supporting the broad implementation of such games in business education.
My Responsibilities
I was responsible for developing the standardized workflow code for the meta-analysis.

The Heterogeneity of Youth Depression Scales

Started on Jul 28, 2022
DOI GitHub OSF
Description
This study systematically examined the heterogeneity of depression scales for Chinese children and adolescents. Across 27 scales, we found substantial differences in symptom coverage and low overlap between instruments. Analyses of data from over 12,000 participants further showed that commonly used scales produced different detection rates and captured distinct symptom profiles. These findings suggest that youth depression scales are not interchangeable and highlight the need for culturally and developmentally adapted assessment tools in non-Western contexts.
My Responsibilities
I contributed to the early-stage coding work and visualized the differences in what the scales measure.

Meta-analysis of Self‑Matching Task

Started on Jul 1, 2021
DOI GitHub OSF
Description
This project is a large-scale meta-analysis examining how newly acquired self-relevance influences cognitive processing. Specifically, it focuses on two widely used associative learning paradigms: the Self-Matching Task (SMT) and the Ownership Paradigm. By systematically reviewing and synthesizing findings across existing studies, the project aims to estimate the overall size of the self-prioritization effect and identify the conditions under which the effect becomes stronger or weaker.
My Responsibilities
I joined this meta-analysis project following the initial coding of 136 papers using the Self-Perceptual Matching Task (SMT). I spearheaded the verification and cross-checking process for these studies and subsequently led the systematic search and coding efforts for newly published literature to ensure the project remained current. As the scope of the study expanded beyond its original goals to improve feasibility, I undertook a comprehensive overhaul of the technical infrastructure, rewriting the analytical code and restructuring the directory architecture. Currently, I continue to lead the project by providing training for new coders on evolving variables and developing R scripts for advanced statistical methodologies.
