Research Projects

Project 1

Beyond the Ten Simple Rules: Reliability, Validity, and Parsimony in Evaluating the RLWMH Models

GitHub

In the field of computational modeling, various estimation methods are available to identify optimal parameter values for black-box functions. However, these methods often yield diverging estimates for the same model. To assess the robustness of different estimation methods, this project uses the open-access data and the RLWMH model from Collins (2025) as a case study. We provide a comprehensive benchmark of different estimation techniques. The goal of this research is to evaluate the stability of these estimation methods. Furthermore, we will systematically increase the number of free parameters, starting from the basic Rescorla-Wagner model and progressing toward the full RLWMH model. This incremental approach allows us to evaluate the model’s parsimony and identify potential parameter redundancy within the RLWMH framework proposed by Collins.

Project 2

binaryRL: Reinforcement Learning Modeling of Two-Alternative Forced Choice Decision Making in R—A Step-by-Step Tutorial.

GitHub OSF DOI

Building reinforcement learning (RL) models can be a steep learning curve for many psychologists. To bridge this gap, we developed an R package that enables researchers to construct complex RL models using intuitive if-else logic. By providing a streamlined workflow, the package simplifies the entire process—from model specification to parameter estimation—making computational modeling accessible to all.

Project 3

Registered reports in psychology across scholarly citations and public dissemination: A comparative meta evaluation of more than a decade of practice

GitHub OSF DOI

This project conducted a meta-analytical comparison of 120 pairs of Registered Reports (RRs) and non-Registered Reports (non-RRs) from 34 psychological journals, matched by journal, publication time, and research topic. It examined the academic recognition (citations) and public dissemination (Altmetric Attention Scores and Twitter posts) of RRs compared to traditional articles, controlling for factors like null-results reporting, transparency, and authorship.

  • Responsibility:
    • Coded collected articles, extracting key information.
    • Used lme4 to build hierarchical linear models to test for differences between RR and non-RR articles in citations and altmetrics, and to identify reasons for such differences.
    • Used Mplus to construct hierarchical linear models, examining whether journal impact factor moderates the relationship between article type (RR vs. non-RR) and dependent variables (e.g., citations and altmetrics).
    • Visualized the results using ggplot2.
    • Responded to reviewers’ statistical questions and provided solutions.
    • Authored the Methods and Results sections of the original draft.

Project 4

A multiverse assessment of the reliability of the self-matching task as a measurement of the self-prioritization effect

GitHub OSF DOI

This project addresses the recently proposed reliability paradox (a phenomenon where a cognitive paradigm exhibits stable experimental effects at the group level, but is unstable at the individual level). It collected 42 datasets (from a total of 22 articles) to examine the reliability of a self-prioritization effect paradigm (self-matching task). Additionally, this paper also examined the reliability of six indices: reaction time (RT), accuracy, efficiency (reaction time / accuracy), d-prime from Signal Detection Theory, and drift rate (v) and start point (z) from the Drift Diffusion Model.

  • Responsibility:
    • Emailed authors to request raw data from papers that utilized the self-matching task.
    • Utilized dplyr and tidyr to clean the raw data.
    • Developed two R packages (yukiSH & yukiBP) for splitting the raw data into two halves to calculate split-half reliability across six indices in this paradigm.
    • Conducted a classic meta-analysis using metafor to demonstrate the robustness of the experimental effect across papers.
    • Visualized the results using ggplot2.
    • Authored the original draft.

Project 5

A Meta-analytical Comparison of the Self Prioritization Effect.

GitHub OSF DOI

This meta-analysis aims to quantify the overall Self-Prioritization Effect (SPE) observed in associative learning tasks, such as the Self-Matching Task and the Ownership paradigm. It will investigate the magnitude, generalizability, and specificity of the SPE, exploring how its effect size varies across different cognitive processes and identifying potential moderators including associative learning task types, baseline conditions, individual differences, experimental procedures, and publication-related factors.

  • Responsibility:
    • Trained recruited coders and assigned coding tasks.
    • Coded collected articles, extracting key information.
    • Conducted a traditional meta-analysis using metafor.
    • Visualized the results using ggplot2.
    • Authored the original draft.

Project 6

The Heterogeneity of Youth Depression Scales

GitHub OSF DOI

Role: Contributor

This study systematically examined the heterogeneity of depression scales for Chinese children and adolescents. Across 27 scales, we found substantial differences in symptom coverage and low overlap between instruments. These findings suggest that youth depression scales are not interchangeable and highlight the need for culturally and developmentally adapted assessment tools in non-Western contexts.

  • Responsibility: I contributed to the early-stage coding work and visualized the differences in what the scales measure.

Project 7

Business Decision-making Game Facilitates Training Effectiveness: A Three-level Meta‑Analysis

GitHub DOI

Role: Contributor

This three-level meta-analysis of 41 studies (N = 8376) reveals that business decision-making games significantly enhance training effectiveness with a moderate overall effect (g = 0.53). These positive outcomes remain robust across various participant types, game designs, and academic fields, supporting the broad implementation of such games in business education.

  • Responsibility: I was responsible for developing the standardized workflow code for the meta-analysis.
